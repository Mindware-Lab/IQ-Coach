# IQ Coach specifications

## Current canonical B2C platform specification

### `IQM_B2C_NODE_PLATFORM_SPEC_v1.md`

Common production framework for the six IQ Mindware / Trident-G B2C cognitive-node apps.

It defines:

- one shared Vite + TypeScript + Supabase platform shell;
- six interchangeable node modules;
- the commercial construct-transfer state machine `A → B → A_RETURN → A_REOPEN → A/B`;
- shared Capacity → Strategy → Niche architecture;
- mission creation and verification;
- environmental / niche redesign;
- central G Track display;
- entitlement-based node unlocking;
- the mutualist network dashboard;
- the minimal Phase-1 data model and node-module code contracts.

For Phase-1 commercial implementation, this specification takes precedence over older research-oriented wrapper-counterbalancing or transfer-measurement documents where they conflict.

Scientific transfer theory remains canonical in:

`Mindware-Lab/trident-g-ground-truth/protocols/IQ_Coach/TRIDENT_G_TRANSFER_MECHANISMS_v1.md`
